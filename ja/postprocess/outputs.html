    出力される計算結果¶

    対応バージョン: 2.0.20261007 の次のリリース

    FreeBird は、計算条件の「出力開始時間」から「出力間隔」ごとに、次の計算結果を出力します。名前は iRIC のポストプロセッサーに表示される名前です（英語のまま表示されます）。

    • 2次元の結果：平面の格子（計算に使った2次元格子）上の値です。2次元ポストプロセッサーで表示します。
    • 3次元の結果：2次元格子を鉛直方向（σ座標）に重ねた3次元格子上の値です。3次元ポストプロセッサーで表示します。
    • ノードは格子点の値、セルはセル中心の値、iFace・jFaceはセル境界の値です。

    「出力される条件」が空欄のものは、常に出力されます。

    時系列の値（グラフ表示用）¶

    時刻ごとに1つの値で、ポストプロセッサーのグラフで表示します。

    名前 内容 出力される条件
    Time 時刻（秒）
    Hydrostatic Flag その時刻の圧力モデルの設定値（0：静水圧、1：非静水圧、2：ハイブリッド）
    Input Discharge 上流端に与えている流量（m³/s） 単一流入・単一流出
    Upstream Stage / Downstream Stage 上流端・下流端の水位（m） 単一流入・単一流出
    Upstream Depth / Upstream Velocity 上流端の水深（m）・平均流速（m/s） 単一流入・単一流出
    Upstream Dsicharge 上流端の断面で計算された流量（m³/s） 単一流入・単一流出
    Qadjust 上流端の流量を目標流量に合わせるための調整量 単一流入・単一流出
    （流入の境界条件の名前） その流入境界に与えている流量（m³/s） 複合河川条件で流入を設定したとき
    （流出の境界条件の名前） その流出境界の水位（m） 複合河川条件で流出を設定したとき
    （流量検査断面の名前） その断面を通過する流量（m³/s） 流量検査断面を設定したとき
    Wind Intensity その時刻に与えている風速（m/s）。開始・終了時の増減を含みます 吹送流の計算がオン

    2次元の結果（ノード）¶

    名前 内容 出力される条件
    Elevation[m] 河床高（m）
    WaterSurf.[m] 水位（m）
    Depth[m] 水深（m）
    BedFluctuation[m] 河床変動量（初期河床からの変化, m）
    DepthAveragedVelocityX/Y 水深平均流速の x・y 成分（m/s）。ベクトル表示用
    X_DepthAveragedVelocity / Y_DepthAveragedVelocity 上と同じ値（コンター表示用）
    SurfaceVelocityX/Y 水面の流速の x・y 成分（m/s）
    SurfaceVerticalVelocity[ms-1] 水面の鉛直流速（m/s）。正が湧き出し、負が沈み込み
    SurfaceVorticity[s-1] 水面の流れの鉛直軸まわりの渦度（1/s）
    BottomVelocityX/Y 底面付近の流速の x・y 成分（m/s）
    X_BottomVelocity / Y_BottomVelocity 上と同じ値（コンター表示用）
    ShearVelocity[ms-1] 底面の摩擦速度（m/s）
    Total-Discharge 単位幅流量（m²/s）
    Curvature 格子の流下方向の曲率
    BedLoadX/Y、X_BedLoad / Y_BedLoad 掃流砂量の x・y 成分 掃流砂の計算がオン
    BedLoadTransport[cm2s-1] 掃流砂量の大きさ（cm²/s） 掃流砂の計算がオン
    ShieldsNumber 無次元掃流力（掃流砂の粒径に対する値） 掃流砂の計算がオン
    ShieldsNumber_sl 無次元掃流力（浮遊砂の粒径に対する値） 浮遊砂の計算がオン
    Wind10X/Y 高さ 10 m の風速の x・y 成分（m/s） 吹送流の計算がオン

    2次元の結果（セル・セル境界）¶

    名前 内容 出力される条件
    Elevation_cell[m] / WaterSurf_cell / Depth_cell[m] セル中心の河床高・水位・水深（m）
    BedFluctuation_cell[m] セルの河床変動量（m）
    ShearVelocity_cell[ms-1] セルの底面の摩擦速度（m/s）
    SurfaceShearVelocity_cell[ms-1] 水面の摩擦速度（m/s） 水面抵抗係数が 0 より大きい
    TotalDischarge_cell[ms-1] セルの単位幅流量
    z0_cell セルの粗度高さ z0（m）
    FixedBed_Cell 固定床セル（1：固定床）
    StructureTop_Cell[m] 障害物ブロック（構造物）の天端の標高（m）
    ShieldsNumber_cell / BedLoad_cell[m2s-1] / TotalBedLoad[m2s-1] セルの無次元掃流力・掃流砂量 掃流砂の計算がオン
    ShieldsNumber_cell_sl / Suspension_cell[ms-1] / usta_wf / Dform_sl 浮遊砂の無次元掃流力・巻上げ量・摩擦速度と沈降速度の比・浮遊砂による河床変動 浮遊砂の計算がオン
    SurfaceConcentration / MidDepthConcentration / BottomConcentration 水面・水深中央・底面の濃度 密度流の計算がオン
    WindIntensity / WindShearIntensity 風速・風による水面せん断応力の大きさ 吹送流の計算がオン
    Discharge_iFace i 方向のセル境界を通過する流量（iFace）

    3次元の結果（ノード）¶

    名前 内容 出力される条件
    X-Velocity / Y-Velocity / Z-Velocity 流速の x・y・z 成分（m/s）。コンター表示用
    3dVelocityX/Y/Z 上と同じ値（ベクトル表示用）
    SecondaryFlowX/Y/Z 二次流ベクトル。格子の流下方向（i 方向）の成分を除いた、横断方向と鉛直方向の流速（m/s）。横断面でのベクトル表示に使います
    X-Timeave-Velocity など / Time_Ave_3dVelX/Y/Z 時間平均流速（「時間平均の開始時間」から「終了時間」までの平均, m/s）
    X-Vorticity / Y-Vorticity / Z-Vorticity 渦度の x・y・z 成分（1/s）
    Pressure 非静水圧の圧力成分。非静水圧モデルで意味をもちます
    Eddy Viscosity 渦動粘性係数（m²/s）
    TurbulentKineticEnergy / TKE_DissipationRate 乱れエネルギー k（m²/s²）とその散逸率 ε（m²/s³） 乱流モデルが標準k-εまたは非線形k-ε
    Concentration 濃度 密度流の計算がオン
    Suspended Sediment Concentration 浮遊砂の濃度 浮遊砂の計算がオン
    BedElevation / SurfaceElevation / Depth その鉛直列の河床高・水位・水深（m）
    Position 格子点の標高（m）
    Sigma σ座標の値（河床 0、水面 1）
    Xi / Eta 格子の i・j 方向の位置を 0〜1 で表した値。断面の位置の指定に使えます
    X-Discharge / Y-Discharge その i 断面・j 断面を通過する流量（m³/s）
    3dObstacle 障害物（1：障害物）。等値面で表示すると障害物の形が見えます
    ThickWallBlock3D 障害物ブロック（構造物）と壁の内部（1：内部）。等値面で表示します
    ThickWallBody / ThinWallBody 厚みのある壁・薄い壁の位置
    FixedBed_Node 固定床（1：固定床）

    3次元の結果（セル・セル境界）¶

    名前 内容
    Obstacle_Cell 障害物セル（1：障害物）
    BedElevation_Cell / SurfaceElevation_Cell / BedFluctuation_Cell セルの河床高・水位・河床変動量（m）。2次元の値を各層に複製したもので、3次元表示で色分けに使えます
    ThinWallCellTrans 薄い壁のセルの透過率
    iFace3d / jFace3d i・j 方向のセル境界が開いているか（1：開いている）
    iWall3dOut / jWall3dOut i・j 方向のセル境界の透過率（壁・カルバートの開口の表示用）

    壁・構造物の点群（パーティクル）¶

    計算条件の「壁およびカルバートの描画」をオンにすると、壁と構造物の形を3次元表示するための点群が出力されます。

    名前 内容
    i-Wall1, i-Wall2, … / j-Wall1, … i方向・j方向の壁
    i-ThickUp1、i-ThickDw1、i-ThickTop1、i-ThickNorth1、i-ThickSouth1 など 障害物ブロック（構造物）の上流面・下流面・天端・側面
    i-BodyAll1、i-BodyTop1、j-BodyAll1 など ポリゴンで設定した障害物ブロック（構造物）の各面と天端（カルバートの開口部を除く）
